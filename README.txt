Dark Room Real Estate Photography
GitHub Pages Preview

This folder is a complete, self-contained static website.

LOCAL PREVIEW

Open index.html in Chrome, Edge, Firefox, or Safari.

GITHUB PAGES

1. Create a new GitHub repository.
2. Upload every item in this folder to the repository root:
   - index.html
   - styles.css
   - images
   - .nojekyll
   - README.txt
3. Open the repository's Settings.
4. Select Pages.
5. Under Build and deployment, select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
6. Save and wait for GitHub to provide the public website URL.

IMPORTANT

Do not upload only index.html. The styles.css file and images folder are
required for the design and photography to display correctly.

Before launch, replace the general HD Photo Hub links with Will's exact
scheduling URL. Concept photographs can later be replaced with final portfolio
images without changing the page structure.
